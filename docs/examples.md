# Input Prolog and output Detlog

These are the real outputs of the converter for every program in `examples/`.

- `examples/memo.pl` was converted with `detlog2 memoise examples/memo.pl --goal 'pick(2, X)' --goal 'pick(5, X)' --complete`.
- Every other example was converted with `detlog2 convert examples/NAME.pl -o OUT`.
- Each output was written only after its proof was accepted. The `%` lines at the top list the rewrite steps the proof records.

Run outside detlog2, the converted programs need nothing but
[`src/detlog_runtime.pl`](../src/detlog_runtime.pl).

[`tests/native_tests.pl`](../tests/native_tests.pl) loads each converted program into plain SWI-Prolog with only that runtime, and runs every query listed below.
It runs the original program, with its cuts, on SWI-Prolog itself.
It then checks that the two give the same answers in the same order, with the same output between them, and that the converted call leaves no choicepoint.
All 30 queries pass.

A predicate `p/n` becomes `p__cp(A1, ..., An, Rows)`, which succeeds exactly once. `Rows` is the answer packet: one row `[A1, ..., An]` per answer, with `out(Text)` items where output was written.

## 1. Independent generators become a splice; a dependent conjunction is spliced row by row

**Input Prolog** (`examples/splice.pl`)

```prolog
% The splice example from the Detlog notes: two generators whose answers
% are combined.  detlog2 computes each packet once and splices them:
%   ?- c(A, B).   A = 1, B = 3 ; A = 1, B = 4 ; A = 2, B = 3 ; A = 2, B = 4.

c(A, B) :- a(A), b(B).
a(A) :- member(A, [1, 2]).
b(B) :- member(B, [3, 4]).

% Three positions, one of them fixed: splice([fixed, cp([1,2]), x], Rows).
triple(X, Y, Z) :- X = fixed, member(Y, [1, 2]), Z = x.

% A dependent conjunction: q/2 needs the answer of p/1.
p(1). p(2). p(3).
q(X, Y) :- p(X), Y is X * 10, Y > 10.
```

## 2. Cuts become if_commit/3 decisions

**Input Prolog** (`examples/cuts.pl`)

```prolog
% Cuts of several kinds.  detlog2 turns each into an explicit decision.

% a :- b, !, c.  a :- d.   becomes   a :- if_commit(b, c, d).
a(X) :- b(X), !, c(X).
a(X) :- d(X).
b(1). b(2).
c(1).
d(3).

% A red cut (meaning-changing) and a green one.
max(X, Y, X) :- X >= Y, !.
max(_, Y, Y).

classify(N, neg) :- N < 0, !.
classify(0, zero) :- !.
classify(_, pos).

% First solution only, with a cut local to findall's goal.
firsts(L, F) :- findall(X, (member(X, L), X > 1, !), F).

% Two cuts in one clause.
two(X, Y) :- member(X, [1, 2, 3]), X > 1, !, member(Y, [a, b]), !.
two(none, none).

% A cut inside \+ is local to it.
no_big(L) :- \+ (member(X, L), X > 5, !).

% "!" here is data (a character list), not a cut.
bang(Out) :- append("Hi", "!", Out).
```

## Mapping summary

| Prolog construct | Detlog form the converter writes |
| --- | --- |
| facts | `member_cp(P, [[Args1], [Args2], ...]), cp_filter(P, [A1, ..., An], Rows)` |
| a clause | `p__cp_cK(Args, Rows)`. Its head is matched by `if_commit(copy_term(Args, HeadArgs), ..., Rows = [])` |
| several clauses | one `p__cp_cK` per clause, joined with `rows_concat/2` |
| `member/2` | `member_cp(P, List), cp_rows(P, PRows)`, then `splice_extend/4` into the environment |
| `between/3` | `between_cp/3` (finite bounds only) |
| independent generators | `splice([cp(P1), cp(P2)], Combos)`, guarded by `splice_safe/1`. The sequential form is generated too, as the fallback |
| dependent conjunction | an iteration predicate `p_cK__cp_J([Row\|Rows], Out)` over the rows of the goals before it, which splices each row and joins the results with `rows_concat/2` |
| a deterministic test (`X > 0`, `Y is ...`) | `if_commit(Test, Out = [Row], Out = [])` |
| `(A ; B)` | `rows_concat/2` of the two packets |
| cut | cut elimination first: the clauses become one chain of `if_commit/3` decisions |
| `->`, `once/1`, `\+/1` | `packet_first/3`, then `if_commit/3` on `none` / `first(Row)` |
| `findall/3`, `aggregate_all/3` | `packet_split/3` of the goal's packet, then `length_det/2` for counts |
| `write/1`, `nl/0`, `format/2` | `effect_text(Goal, Text)` and an `out(Text)` item in the packet |
| a cut the converter does not support | a complete memo table: `memo_lookup/3`, or `memo_miss/2` (an error) |

The output never contains `!`, `;`, `->`, `\+` or a generator call. `detlog2 check` and `tests/native_tests.pl` confirm that every converted call succeeds exactly once.

## Differences from the earlier sketch

An earlier sketch of these examples was written by hand and does not match what the converter writes:

- **Example 1 (`a/1`, `b/1`).** `member/2` becomes `member_cp(P, [1, 2]), cp_rows(P, PRows)`; `cp_filter/3` is used only for facts.
  - `c/2` splices with `splice/2` when `splice_safe([[A], [B]])` holds.
  - Otherwise it runs the generated sequential form, `c_c1__cp_1/2`. There is no `sequential_fallback` atom.
- **`det_sum/2`.** It is not `if_commit(S = 0, Rows = [[]], Rows = [])`.
  - Each clause is its own `det_sum__cp_cK`, and the two are joined with `rows_concat/2`.
  - The recursive call's packet is spliced by `det_sum_c2__cp_1/2`, which tests `S is H + Rest` row by row.
- **Example 5 (`pick/2`).** The memo table for `pick(5, X)` is `[[5, big]]`, not `[5, big], [5, huge], [5, other]`.
  - The cut in `( N > 3 -> member(X, [big, huge]), ! ; ... )` commits the whole predicate after the first answer.
- **`a/1` in `cuts.pl`.** Cut elimination does not give `a(X) :- if_commit(b(X), c(X), d(X))`.
  - It gives `a__cp`: `b`'s packet is taken through `packet_first/3`.
  - Then `if_commit(Res = none, ...)` either takes `d/1`'s packet, or runs `c/1` on the first row of `b/1`.
- **Dependent conjunction (`q/2`).** There is no `splice_extend(PX, Env, [X], Env1)` call on an unbound environment.
  - `p/1`'s packet is spliced into `[X, Y]`.
  - Then `q_c1__cp_1/2` runs `Y is X * 10, Y > 10` as one `if_commit/3` test per row.
